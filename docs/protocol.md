# 线协议（版本 1）

所有协议头使用 ASCII、以 `\n` 结束，最大长度为 512 字节。协议头之后的数据连接切换为透明 TCP 字节流，不再解析消息。连接 ID 为服务端生成的无符号十进制整数。

| 方向 | 消息 | 含义 |
| --- | --- | --- |
| 客户端 → 服务端 | `HELLO <token>\n` | 建立常驻控制连接 |
| 服务端 → 客户端 | `OK\n` | 认证成功 |
| 服务端 → 客户端 | `OPEN <id>\n` | 有新的公开连接等待配对 |
| 客户端 → 服务端 | `DATA <token> <id>\n` | 将新连接认领为数据连接 |
| 服务端 → 客户端 | `OK\n` | 数据连接配对成功，后续传输原始字节 |
| 服务端 → 客户端 | `PING\n` | 控制连接心跳 |
| 客户端 → 服务端 | `PONG\n` | 心跳回应 |

拒绝认证、无效 ID、超时、连接过多等情况时，服务端直接关闭对应连接。客户端断开时，服务端清理尚未配对及正在转发的连接。公开连接如果迟迟没有数据连接配对，也会超时关闭。

协议简单且尚无版本协商。`token` 不能包含空格或换行，建议使用随机十六进制字符串。该协议**不加密**；在公网使用时，应通过可信的加密网络承载。
